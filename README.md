アプリ名: NovelFlow（小説版YouTube / 没入型ショート＆通常小説プラットフォーム）

概要: 1話完結のショート小説から章仕立ての通常小説までサクッと没入して読める、マルチデバイス対応のWebアプリケーション。
全てGoogle AI Studioで作りました。私自身はHTMLやCSSを少し触った程度の知識しかありません。

主な機能:

ショート小説の全画面スワイプビューア

羊皮紙テクスチャを活かしたクラシカルな読書UI

ユーザーアカウント作成・マイページ機能（投稿・お気に入り・しおり管理）

いいね・閲覧数のリアルタイム永続化・同期機能

使用技術: React / Next.js, Tailwind CSS, TypeScript, Supabase / Node.js バックエンド
