# NovelFlow (ノベルフロー)

> **没入型スワイプ操作で短編小説を直感的に楽しめる「ショート動画感覚のWeb小説プラットフォーム」**
> 
> SNSのショート動画のようにスキマ時間で手軽に読書を味わえる「ショート小説」と、羊皮紙テクスチャで落ち着いて楽しめる「長編小説」をシームレスに統合した次世代の読書体験Webアプリケーションです。

## 📖 プロジェクト概要 (Overview)

現代の「活字離れ」や「可処分時間の奪い合い」という課題に対し、**「TikTokやYouTube Shortsのように、1話数分で没入できる読書体験があれば、読書のハードルを劇的に下げられるのではないか」**という着想から開発しました。

文字を読む心地よさを最大化するため、**読書体験を1ミリも阻害しないミニマルなUI/UX設計**、**文章単位で感動をストックできる「フレーズいいね」機能**、**ユーザーの嗜好に応じた動的レコメンドエンジン**を独自実装しています。

## ✨ 主な機能 (Key Features)

### 1. 📱 縦スワイプ没入型ショート小説ビューア
- **フルスクリーンスワイプ**: タッチ/ドラッグ操作に吸い付くような慣性スクロール（Framer Motion）。
- **中央タップHUD**: 不要なボタンを排し、読書中は本文に100%集中可能。
- **クイックリアクション**: スワイプの手を止めることなく「いいね」「しおり」が可能。

### 2. 📖 単ページ羊皮紙スタイル長編小説ビューア
- **羊皮紙ブックデザイン**: 紙の本の温かみを再現した落ち着いた背景とタイポグラフィ。
- **ノド（綴じ代）の影を排除した可読性重視レイアウト**: 文字の上に影が重ならないよう緻密に計算された余白設計。
- **フォントサイズ調整 & 話数ジャンプ**: 読者の好みに合わせた文字サイズ変更と進捗の自動保存。

### 3. 💬 フレーズいいね & 引用コレクション（独自機能）
- **心に響いた一文のストック**: 本文中の気になるセンテンスを選択して「フレーズいいね」を記録。
- **SNS共有カード風UI**: 引用文・作品名・作者名・コンテキストを美しくクリップボードにコピー可能。
- **レイアウト非破壊レンダリング**: ハイライト付与時にも改行位置や文字送りが一切崩れない安全なテキスト分割処理。

### 4. 🧭 ユーザー嗜好連動型 レコメンドエンジン
- **リアルタイム嗜好スコアリング**: ユーザーの「いいね」「フレーズいいね」からジャンル親和度を算出。
- **説明可能な推薦タグ（Explainable AI/RecSys）**:
  - `✨ あなたの推しカテゴリ`（最高親和度ジャンル）
  - `🧭 未開拓ジャンル`（フィルターバブルを防ぐセレンディピティ枠）
  - `🔥 読者に大人気の話題作` / `🌟 編集部おすすめの注目作`（コールドスタート時）
- **新規作品ブースト**: お気に入りジャンルの未読作品に出会いやすくなるスコア補正を導入。

### 5. 📲 モバイル最適化ボトムナビゲーション
- スマホ閲覧時でも「おすすめ」「ショート」「通常小説」「マイページ」へ親指一本で迷わずアクセス。
- 好み作品の更新時にはタブ上にさりげないパルスインジケーターを表示。

### 6. 👤 マイページ（フォーマット別一元管理）
- 「投稿作品」「しおり・読書履歴」「いいねした作品」「おすすめ作品」「フレーズいいね」をタブ管理。
- 「すべて / ショート小説のみ / 通常小説・連載のみ」のクイックフィルターで読みたい形式を即座に絞り込み。

## 💡 技術的な工夫と解決した課題 (Engineering Highlights)

### 1. 【UI/UX & パフォーマンス】フレーズいいね時の文字送り・改行ズレ防止
- **課題**: テキスト選択・フレーズ保存時にDOMツリーを再生成したりインライン要素を不用意に挿入すると、ブラウザの折返し計算（Text Reflow）が走り、行末の文字送りやスクロール位置がガタついて読書体験を大きく損ねていた。
- **アプローチ**:
  - 本文全体を無闇に再マウントせず、ページ内の文字列インデックスに基づいた**非重複レンジスライシング（Non-overlapping Range Slicing）**アルゴリズムを実装。
  - テキストノードのフォントメトリクス（`letter-spacing`, `line-height`, `word-break`）を厳密に継承した軽量インラインラッパーのみを適用。
- **成果**: フレーズ保存の瞬間もテキストの揺れや再描画ノイズがゼロになり、紙の本のようなストレスフリーな読書感を実現。

### 2. 【アルゴリズム】嗜好分析に基づくレコメンドとコールドスタートの両立
- **課題**: 初回訪問ユーザーはいいね履歴がないため推薦精度が落ちる（コールドスタート問題）。また、同一ジャンルだけを推薦し続けると「フィルターバブル」に陥る。
- **アプローチ**:
  - **ハイブリッド推薦モデル**: ユーザーの蓄積データがある場合は「カテゴリ親和度 × 作品人気度」、初回やデータ不足時は「全体の話題度・評価数」をベースにしたスコアリングに自動フォールバック。
  - **セレンディピティの担保**: 親和度外の作品群からも高評価作を「未開拓ジャンル枠」として一定比率で抽出し、好みのジャンル内でも未読・未いいね作品をブースト（+15pt）する探索ロジックを設計。
- **成果**: 個別最適化されたおすすめと、新しいジャンルとの偶発的な出会いが心地よく共存するフィードを実現。

### 3. 【状態管理 & 整合性】楽観的UI更新（Optimistic UI）とデータ競合の解消
- **課題**: 通信遅延を隠蔽するためにクライアント側で即座にUIを書き換える「楽観的更新」を行った際、いいね解除や連続タップ、アカウント切り替えによって古いローカルキャッシュが復活してしまうデータ不整合が発生。
- **アプローチ**:
  - ユーザーIDスコープでストレージキーを明確に分離。
  - サーバーの真値（Server Truth）とクライアントの一時状態を突合し、失敗時のロールバックと最新レスポンスの優先マージを徹底。
- **成果**: ネットワーク待機ゼロの高速な操作フィールを維持しつつ、リロードやアカウント切り替え後も100%正しいリアクション数を担保。

```text
novelflow/
```

## 🚀 ローカル環境での起動方法 (Getting Started)

### 前提条件
- Node.js (v18以上推奨)
- npm または yarn / pnpm / bun

### 手順
```bash
# 1. リポジトリのクローン
git clone https://github.com/your-username/novelflow.git
cd novelflow

# 2. 依存関係のインストール
npm install

# 3. 開発サーバーの起動 (Vite + Express)
npm run dev

# 4. ブラウザでアクセス
# http://localhost:3000
```
